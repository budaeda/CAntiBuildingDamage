# CAntiBuildingDamage

# About

Prevents Structure And Barricade Damage
Has A Destroy Whitelist For Barricades/Structures You Want Players To Be Able To Destroy

# Configuration

```xml
<?xml version="1.0" encoding="utf-8"?>
<CrestAntiDamageConfiguration xmlns:xsd="http://www.w3.org/2001/XMLSchema" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance">
  <WhitelistedDestroy>
    <unsignedShort>369</unsignedShort>
    <unsignedShort>328</unsignedShort>
  </WhitelistedDestroy>
</CrestAntiDamageConfiguration>
```
